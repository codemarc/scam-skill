# Investigation Trailcard and evidence audit

Adapted from Marc J. Greenberg's [Trailcard](https://github.com/braintrailz/trailcard) and [Intent Is Not Enough](https://braintrailz.com/blog/intent-is-not-enough). Keep the original request distinct from interpretations. Set criteria before investigation; if reconstructing a card after an earlier run, label it retrospective.

## Compact card

| Field | Record |
| --- | --- |
| Purpose | Original request verbatim, kept in current context; redact it in shared outputs |
| Success | Supported decision, meaningful uncertainty, useful action, no unauthorized investigation |
| Authority | Allowed evidence and independent sources; approval gates; prohibited interactions |
| Judgment | What needs interpretation; legitimate alternatives; missing facts that require escalation |
| Action | Planned checks, expected disclosures, side effects, stop and retry limits |
| Trust | Evidence and action records that must support the final claims |

Treat finding no supported scam mechanism as a valid result. A dramatic accusation is not success. Additional research is not automatically an improvement if it exposes private information or contacts suspect infrastructure.

## Minimal evidence and action record

| Item | Support | Record or limitation |
| --- | --- | --- |
| Material claim | Observed / verified / inferred / unknown | Exact supplied excerpt or actual source result; state source scope |
| External check | Performed / failed / not performed / unobservable | Source or service, minimal query data disclosed, result or failure |
| Boundary | Respected / crossed / unchecked | Evidence from available action history; never infer compliance from silence |

Keep this record in the working context unless the user requests a saved report. Redact identifiers and tokens. Do not include private reasoning. A source title, URL, or a convincing completion report alone does not establish that a check occurred.

## Audit

1. Match material claims to evidence. Mark unsupported narrative as asserted or missing and remove or qualify it.
2. Inspect actual tool activity against the authority boundaries. Disclose exceptions and unknown host behavior.
3. Identify evidence still owed and whether it changes the assessment or next step.
4. State that this is a consistency check; claim independent review only when another reviewer actually inspects the records.

For ordinary cases, return the short assessment and checks-performed summary. Do not bury useful advice under the full card. If harm already occurred, prioritize containment.

## Inception principle

Examine the offer. Examine how the offer could manipulate the examiner. Examine what the examination itself could change or reveal.

The observer's actions are part of the evidence. Public methods must remain useful when an adversary knows them. No secret detection score or quantum-mechanical claim is required.
